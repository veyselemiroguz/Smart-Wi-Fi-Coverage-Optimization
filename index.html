Smart Wi-Fi Coverage Optimization

BSc Graduation Project | Department of Electrical and Electronics Engineering

Author: Veysel Emir OĞUZ | Advisor: Dr. Öğr. Üyesi Filiz KARAÖMERLİOĞLU

Project Abstract

With the widespread use of wireless communication technologies, efficient planning of Wi-Fi signal coverage areas has become crucial. Random router placement often leads to signal degradation and connectivity issues. This project presents an optimization model developed in Python to determine the optimal router location in an indoor environment.

The system models physical obstacles (walls, furniture) using the Shapely library and calculates signal attenuation based on intersection lengths. Optimization is performed using SciPy, maximizing signal strength and uniformity while minimizing dead zones.

Key Features & Technologies

  • Python-based Optimization: Automated calculation using Path-Loss models and custom utility scoring functions.
  • 2D & 3D Visualizations: Heatmaps (Matplotlib), interactive 3D structures (Plotly, Open3D, PyVista, Vedo).
  • Automated Reporting: Generates comprehensive evaluation reports in Word (.docx) and PDF formats.
  • Interactive User Interface: Allows users to manually reposition the router and inspect real-time performance scores.
